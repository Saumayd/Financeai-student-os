# 💻 FinanceAI Student OS (v2.5)

A retro-CRT themed financial dashboard and expense management system tailored for university students (NSUT Delhi edition)[cite: 1]. Built with a hybrid architecture that runs both as a standalone client-side simulator (`localStorage`)[cite: 1] and a full-stack **Node.js + Express** REST API application.

## ✨ Features
- **Reactive Financial Analytics:** Real-time Chart.js cashflow bar charts, category breakdown doughnuts, and dynamic Financial Health grading (`A+` to `C`).
- **Tesseract OCR Receipt Simulator:** Interactive laser-scanner modal and 1-click preset campus receipt parsers (`POST /api/v1/ocr`)[cite: 1].
- **Student AI Advisor:** Rule-based campus financial assistant for checking canteen burn rates and purchase affordability[cite: 1].
- **Built-in Backend DevTools:** Slide-out drawer featuring a live HTTP request terminal, JSON database inspector, and REST API sandbox[cite: 1].
